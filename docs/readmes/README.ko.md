VRCT-VOX는 [VRCT](https://github.com/misyaguziya/VRCT)를 기반으로 한 독립적인 개발 fork이며 공식 VRCT 배포판이 아닙니다.

speech.cpp TTS, 외부 음성 변환, 실시간 음성 인식 및 번역 음성을 개발하고 있습니다. 아직 배포 및 Windows 검증이 완료되지 않았습니다.
