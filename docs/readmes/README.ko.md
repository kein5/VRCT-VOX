VRCT-VOX는 음성 인식(ASR), 음성 합성(TTS), 음성 변환(RVC), 채팅 읽기(OCR), 번역을 하나로 묶은 VRChat용 데스크톱 앱입니다. [VRCT](https://github.com/misyaguziya/VRCT)를 바탕으로 kein5가 개발하며, 공식 VRCT 배포판이 아니고 VRCT 개발자나 VRChat의 승인을 받은 것도 아닙니다.

현재 버전은 [0.1.0-beta.1](https://github.com/kein5/VRCT-VOX/releases/tag/v0.1.0-beta.1)(프리릴리스)입니다. Linux(AppImage, tar.gz)는 실제 모델로 시험했고, Windows 빌드는 아직 실제 PC에서 시험하지 않았습니다.

원본 [LICENSE](/LICENSE)와 저작권 표시는 유지됩니다. 모델은 동봉하지 않으며 OCR 모델도 배포물에 포함하지 않습니다. VRCT-VOX에 관한 문의는 원본 VRCT 개발자에게 보내지 마세요.
