# VRCT-VOX

VRCT-VOX 是基於 [VRCT](https://github.com/misyaguziya/VRCT) 的獨立開發 fork，並非 VRCT 官方發行版。

本專案新增 speech.cpp TTS、外部變聲、即時語音辨識和翻譯語音。發行套件與 Windows 實機驗證尚未完成。

- [功能、授權與原作者致謝（English）](/docs/readmes/README.en.md)
- [VRCT-VOX 發行頁](https://github.com/kein5/VRCT-VOX/releases)
- [本 fork 的支援與問題回報](https://github.com/kein5/VRCT-VOX/issues)

保留原始 [LICENSE](/LICENSE) 和著作權聲明。OCR 模型與僅供驗證的 Mia2026 不會放入發行套件。請勿將本 fork 的問題送往原專案的支援窗口。
