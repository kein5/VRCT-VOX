# TTS・RVCの設定モックアップ

[トップ画面](main.html)・[TTS設定](mockup.html)・[RVC設定](rvc.html)をブラウザーで開く。
TTSとRVCを別ページに分け、トップ画面には各トグルを1行ずつ追加する案。
製品コードへの適用はまだ行っていない。

各HTMLはCSSとアイコンを内蔵し、単独で表示できる。ページ移動を試す場合は3つを同じフォルダーへ置く。
ローカルHTTPサーバーは不要。音声・マイク・モデル・OSC・製品設定には接続しない。

- トップ: TTSとRVCをクリック/Spaceで切替。両ON・片方ON・準備不足・起動中は上の表示選択から確認。
- TTS: 読み上げ対象・出力先・シード・InstructionとTTSエンジン。保存、CPU再試行を模擬。
- RVC: 入力マイク・実行環境・モデル・ピッチ・任意index。保存と数値検証を模擬。
- 各OFFはその機能だけを停止する設計。トグルの下に状態・停止・設定リンクは置かない。
- メニューと戻るリンクはTTS/RVCのON/OFF例を引き継ぐ。実行中のRVC設定は編集不可。
- 共通経路は「デバイス」に置く提案。TTS/RVCは現在値を表示する。デバイスページのモックは今回の対象外。
  両ONの例は同じ管理仮想マイクへ出力。TTSだけ別のイヤホンに分離する動作は示していない。
- 各フォームの保存・入力マイクの選択はそのページ内だけの表示例。ページ移動で入力内容は保持しない。
  実装時は未保存確認と、選択した入力のアプリ共通保持が必要（計画に記載）。

既存VRCTの4スイッチ・言語設定・ログ・入力欄の配置を維持する。モックの周辺領域は概略で、
既存部品をこのHTML/CSSで置換する提案ではない。原音/Seed-VCは既存詳細設定、ASR管理は文字起こしに置く。
