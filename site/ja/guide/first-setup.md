# 最初の設定

文章を翻訳してVRChatのチャットボックスへ送るところまでを設定します。読み上げや字幕は、そのあとで機能ガイドを見ながら足してください。

![VRCT-VOXのメイン画面](/screenshots/ja/main.webp)

## 1. VRChatのOSCをオンにする

VRCT-VOXは、OSCという仕組みでVRChatのチャットボックスへ文字を送ります。VRChatのアクションメニューから「Options」→「OSC」を開き、「Enabled」にしてください。

VRCT-VOXの送信先は、初期設定で`127.0.0.1`のポート`9000`です。VRChatのOSCの初期設定と同じなので、ふつうは変える必要はありません。変えるときは、設定の「高度な設定」→「OSC IP Address」と「OSC Port」で変更します。

## 2. 言語を選ぶ

メイン画面の左にある「言語設定」で、次の2つを選びます。

- 「あなたの言語」は、自分が話したり入力したりする言語です。
- 「相手の言語」は、翻訳先の言語です。3つまで選べます。

## 3. マイクとスピーカーを選ぶ

メイン画面の左下の歯車から設定を開き、「デバイス」で選びます。

- 「マイク」は、自分の声を拾うマイクです。LinuxではPipeWireの入力が並びます。
- 「スピーカー」は、ほかのプレイヤーの声を聞き取るときに使う出力です。

「自動選択」をオンにすると、システムの既定のデバイスを使います。

## 4. 送ってみる

メイン画面の左で「翻訳」をオンにします。下の入力欄に文章を入れて送信すると、翻訳した文がチャットボックスに出ます。

::: tip 翻訳モデルの取得
ローカルの翻訳モデルが未取得だと、翻訳できません。設定の「翻訳」で取得するか、外部の翻訳APIを選んでください。詳しくは[翻訳](../features/translation)を見てください。
:::
