# 最初の設定

文章を翻訳してVRChatのチャットボックスへ送るところまでを設定します。読み上げや字幕はそのあとで機能ガイドを見ながら足してください。

![VRCT-VOXのメイン画面](/screenshots/ja/main.webp)

## 1. VRChatのOSCをオンにする

VRCT-VOXはOSCという仕組みでVRChatのチャットボックスへ文字を送ります。VRChatのアクションメニューから「Options」→「OSC」を開き、「Enabled」にしてください。

VRCT-VOXの送信先は初期設定で`127.0.0.1`のポート`9000`です。VRChatのOSCの初期設定と同じなので、ふつうは変える必要はありません。変えるときは、設定の「高度な設定」→「OSC IP Address」と「OSC Port」で変更します。

OSCが有効なVRChatをこのPCで検出できたかは、「設定」→「VRChat」のページの先頭と、メイン画面の「クイック設定」で確かめられます。

## 2. 言語を選ぶ

メイン画面の左にある「言語設定」で次の2つを選びます。

- 「あなたの言語」は自分が話したり入力したりする言語です。
- 「相手の言語」は翻訳先の言語です。3つまで選べます。

## 3. マイクとスピーカーを選ぶ

メイン画面の左下の歯車から設定を開き、「デバイス」で選びます。

- 「マイク」は自分の声を拾うマイクです。LinuxではPipeWireの入力が並びます。
- 「スピーカー」はほかのプレイヤーの声を聞き取るときに使う出力です。

「自動選択」をオンにするとシステムの既定のデバイスを使います。

## 4. 送ってみる

メイン画面の左で「翻訳」をオンにします。翻訳モデルが未取得のときは取得する内容を確かめる画面が開きます。提供元・ライセンス・容量を確かめて同意すると取得が始まり、終わると翻訳がオンになります。

下の入力欄に文章を入れて送信すると、翻訳した文がチャットボックスに出ます。

::: tip 翻訳モデルの取得
まだ取得していないモデルは、会話が空のメイン画面の「使う前の準備」にも出ます。そこのボタンからも同じ確認の画面を開けます。ローカルのモデルを使わないときは、設定の「翻訳」で外部の翻訳APIを選んでください。詳しくは[翻訳](../features/translation)を見てください。
:::
