# 最初の設定

文章を翻訳してVRChatのチャットボックスへ送るところまでを設定します。読み上げや字幕はそのあとで機能ガイドを見ながら足してください。

![翻訳をオンにして会話しているVRCT-VOXのメイン画面](/screenshots/ja/main.webp)

左にスイッチと言語、右に会話のログ、下に入力欄があります。

## 1. 利用状況の送信を選ぶ

最初に起動すると、利用状況の送信をお願いする画面が出ます。「送信する」「送信しない」「あとで決める」から選んでください。どれを選んでもアプリの機能は変わりません。送る内容は[プライバシー](./privacy)にあります。

## 2. VRChatのOSCをオンにする

VRCT-VOXはOSCという仕組みでVRChatのチャットボックスへ文字を送ります。VRChatのアクションメニューから「Options」→「OSC」を開き、「Enabled」にしてください。

メイン画面の右上の「クイック設定」を開くと、OSCが有効なVRChatをこのPCで検出できたかが出ます。「設定」→「VRChat」の先頭にも同じ表示があります。

![「クイック設定」を開いたところ。VRChatを検出したと表示されている](/screenshots/ja/quick-settings.webp)

送信先は初期設定で`127.0.0.1`のポート`9000`です。VRChatの初期設定と同じなので、ふつうは変えません。変えるときは「設定」→「VRChat」の「OSC」で変更します。

## 3. 言語を選ぶ

メイン画面の左にある「言語設定」で次の2つを選びます。

- 「あなたの言語」は自分が話したり入力したりする言語です。
- 「相手の言語」は翻訳先の言語です。3つまで選べます。

## 4. 翻訳をオンにして送る

メイン画面の左で「翻訳」をオンにします。翻訳モデルがまだないときは、取得する内容を確かめる画面が開きます。提供元・ライセンス・容量を確かめて同意してください。取得が終わると翻訳がオンになります。

下の入力欄に文章を入れて送信すると、原文と訳文がログに出ます。VRChatのチャットボックスにも同じ内容が出ます。

::: tip ローカルのモデルを使わないとき
「設定」→「翻訳」で外部の翻訳APIを選べます。詳しくは[翻訳](../features/translation)を見てください。
:::

まだ取得していないモデルは、会話が空のときのメイン画面にある「使う前の準備」にも並びます。

## 5. マイクとスピーカーを選ぶ

声を使う機能（字幕、テキスト読み上げ、ボイスチェンジャー）の前に選びます。メイン画面の左下の歯車から設定を開き、「デバイス」を開いてください。

- 「マイク」は自分の声を拾うマイクです。LinuxではPipeWireの入力が並びます。
- 「スピーカー」はほかのプレイヤーの声を聞き取るときに使う出力です。

「自動選択」をオンにするとシステムの既定のデバイスを使います。
