# 困ったとき

## チャット読み取りで「ウィンドウが見つかりません」と出る

- VRChatを起動してから、チャット読み取りをオンにしてください。
- 「設定」→「VRChat」の「ウィンドウ名」が、使っているクライアントのタイトルと合っているかを確かめてください。初期設定は`VRChat`です。
- Linuxでは、X11/XWaylandのウィンドウとして動いているVRChatを、ウィンドウ名で探します（Protonの初期設定）。gamescopeの中など、ネイティブのWaylandのウィンドウとして動いているときは、先にウィンドウを共有してください（[チャット読み取り](../features/chat-reading)）。

## モデルがないと表示される

その機能のページで、モデルを取得して「モデルパスを適用」まで行ってください（[モデルの取得](./models)）。読み上げや音声認識では、そのあと「サーバーを起動」も必要です。

## 読み上げがVRChatで聞こえない

1. 「設定」→「デバイス」→「音声経路」がミュートになっていないかを確かめ、ミュートなら「音声を再開」を押します。
2. 「設定」→「TTS」の出力先と、VRChatのマイクの選択が合っているかを確かめます（[Linuxの音声経路](./linux-audio)）。
3. 同梱サーバーが起動しているかを確かめます。アプリを再起動すると、サーバーは停止した状態に戻ります。
4. VRChatのマイクテストは、短く録音してから再生する仕組みです。入力のメーターが動いている間にテストを始めてください。

## マイクが開けない（Windows）

Windowsのバージョンによっては、マイクを初めて使うときに、VRCT-VOXへのアクセスを許可するかどうかを確認します。許可してから、もう一度開始してください。

ファイアウォールの確認など、別の確認の画面が開いている間も拒否されます。その確認に答えてから、もう一度開始してください。

ファイアウォールの確認は、VRChatがOSCQueryでVRCT-VOXを見つけるための待ち受けについて聞いています。「アクセスを許可する」を選んでください。キャンセルしたり閉じたりすると、WindowsはVRCT-VOXの受信をブロックする規則を作ります。

確認に答えないままVRCT-VOXを閉じると、次からは確認が出ないまま拒否されます。設定の「プライバシーとセキュリティ」→「マイク」を確かめてください。

## 音声タイピングで貼り付けられない（Linux）

- 貼り付けられるのは、X11/XWaylandのウィンドウとして動いているVRChatです（Protonの初期設定）。ネイティブのWaylandのウィンドウには貼り付けられません。このときも、文はクリップボードへコピーされているので、手動で貼り付けられます。
- KDEでは、初めて貼り付けるときに、入力デバイスの操作を許可するかどうかをデスクトップが確認します。許可してください。
- 貼り付け先は、SteamVRで実行中のアプリのウィンドウです。SteamVRが動いていないときは、クリップボードへのコピーまでを行います。

## もう一度起動しても、新しいウィンドウが開かない

VRCT-VOXは1つだけ起動します。動いている間にもう一度起動すると、動いているウィンドウを前に出します。

## 二重に読み上げられる

VRCT-TTSなど、同じチャットを読み上げる別のツールをオフにしてください。

## ウィンドウが真っ黒・何も表示されない（Linux）

- モニターがスリープしている間は、デスクトップがウィンドウを描かないため、画面が止まったように見えます。モニターを点けてから確かめてください。
- NVIDIAのGPUでは、AppImageが表示の不具合を避けるための設定を自動で入れます。このとき、ウィンドウの透明化は使えません。

## ログの場所

| OS | 場所 |
|---|---|
| Linux | `~/.config/vrct-vox/logs` |
| Windows | アプリのフォルダーの`logs` |

## 不具合を報告する

[VRCT-VOXのIssues](https://github.com/kein5/VRCT-VOX/issues)に、次のことを書いてください。

- OSと、VRCT-VOXの版
- 起きたことと、そこまでの手順
- ログ。個人情報、APIキー、会話の内容は消してから貼ってください

::: danger 本家VRCTへは報告しないでください
VRCT-VOXについての質問や報告を、本家VRCTの開発者へ送らないでください。
:::

セキュリティの問題は、公開のIssuesではなく、[SECURITY.md](https://github.com/kein5/VRCT-VOX/blob/develop/SECURITY.md)の方法で非公開で知らせてください。
