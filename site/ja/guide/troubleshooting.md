# 困ったとき

## チャット読み取りで「ウィンドウが見つかりません」と出る

- VRChat を起動してから、チャット読み取りをオンにしてください。
- 「設定」→「チャット読み取り」の「ウィンドウ名」が、使っているクライアントのタイトルと合っているかを確かめてください。初期設定は `VRChat` です。
- Linux では、VRChat を X11/XWayland のウィンドウとして動かす必要があります（Proton の初期設定）。

## 「モデルがありません」と出る

その機能のページで、モデルを取得して「モデルパスを適用」まで行ってください（[モデルの取得](./models)）。読み上げや音声認識では、そのあと「サーバーを起動」も必要です。

## 読み上げが VRChat で聞こえない

1. 「設定」→「デバイス」→「音声経路」がミュートになっていないかを確かめ、ミュートなら「音声を再開」を押します。
2. 「設定」→「TTS」の出力先と、VRChat のマイクの選択が合っているかを確かめます（[Linux の音声経路](./linux-audio)）。
3. 同梱サーバーが起動しているかを確かめます。アプリを再起動すると、サーバーは停止した状態に戻ります。
4. VRChat のマイクテストは、短く録音してから再生する仕組みです。入力のメーターが動いている間にテストを始めてください。

## 二重に読み上げられる

VRCT-TTS など、同じチャットを読み上げる別のツールをオフにしてください。

## ウィンドウが真っ黒・何も表示されない（Linux）

- モニターがスリープしている間は、デスクトップがウィンドウを描かないため、画面が止まったように見えます。モニターを点けてから確かめてください。
- NVIDIA の GPU では、AppImage が表示の不具合を避けるための設定を自動で入れます。このとき、ウィンドウの透明化は使えません。

## ログの場所

| OS | 場所 |
|---|---|
| Linux | `~/.config/vrct-vox/logs` |
| Windows | アプリのフォルダーの `logs` |

## 不具合を報告する

[VRCT-VOX の Issues](https://github.com/kein5/VRCT-VOX/issues) に、次のことを書いてください。

- OS と、VRCT-VOX の版
- 起きたことと、そこまでの手順
- ログ。個人情報、API キー、会話の内容は消してから貼ってください

::: danger 本家 VRCT へは報告しないでください
VRCT-VOX についての質問や報告を、本家 VRCT の開発者へ送らないでください。
:::

セキュリティの問題は、公開の Issues ではなく、[SECURITY.md](https://github.com/kein5/VRCT-VOX/blob/develop/SECURITY.md) の方法で非公開で知らせてください。
