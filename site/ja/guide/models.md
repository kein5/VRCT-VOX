# モデルの取得

VRCT-VOX の配布物には、読み上げ・音声認識・声の変換・文字認識のモデルを入れていません。使うモデルは、設定画面から取得するか、手元のファイルを指定します。

## 取得の流れ

1. 各ページの「既定モデルのダウンロード」で、「取得内容を確認」を押します。
2. 提供元、モデル名、正確な容量、利用条件へのリンク、保存先を確かめます。
3. 同意のチェックを入れて、「同意してダウンロード」を押します。取得中は取り消せます。
4. 取得と検証が終わったら、「モデルパスを適用」を押します。対象のサーバーや入力は、先に停止しておいてください。

取得しただけ、適用しただけでは、サーバーの起動、読み上げ、マイクの使用は始まりません。

::: info ファイルの確認
取得したファイルは、容量と SHA-256 を確かめてから使います。取得先は、固定した Hugging Face のリポジトリと版だけです。
:::

| 日本語の読み上げ（軽量） | Irodori-TTS v4.1 Small MF · Q8_0 | 1.12 GiB | MIT + Apache-2.0 |
| ほかの言語の読み上げ | Qwen3-TTS 12Hz 0.6B CustomVoice · Q8_0 | 1.13 GiB | Apache-2.0 |
| ほかの言語の読み上げ（軽量） | Qwen3-TTS 12Hz 0.6B CustomVoice · Q5_K | 0.81 GiB | Apache-2.0 |
| 音声認識（日本語） | Haas-ja v1.0 · Q8_0 | 0.61 GiB | Apache-2.0 |
| 音声認識（30 言語） | Qwen3-ASR 0.6B · Q8_0 | 0.78 GiB | Apache-2.0 |

翻訳のモデルは「設定」→「翻訳」で取得します（[翻訳](../features/translation)）。

## GPU とメモリの目安

読み上げのページでは、GPU の名前と、合計・空きのメモリを表示し、空きに合わせて標準か軽量のモデルを勧めます。これは目安で、メモリの予約や動作を保証するものではありません。VRChat などと同時に使うときは、余裕を多めに見てください。

## 保存先

取得したモデルは、設定ファイル（`config.json`）と同じフォルダーの `downloaded_models` に保存します。Linux では `~/.config/vrct-vox/downloaded_models` です。

## 起動時の自動取得

「設定」→「その他」の「起動時に翻訳・文字起こしモデルをダウンロード」をオンにすると、次の起動時に、まだない内蔵の翻訳・文字起こしモデルを取得します。初期設定はオフです。オフでも、取得済みのモデルは使えます。
