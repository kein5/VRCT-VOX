# プライバシー

## 利用状況の送信はしません

本家 VRCT にある利用状況の送信（Aptabase のテレメトリー）は、VRCT-VOX では無効にしています。古い設定のキーファイルが残っていても送りません。アプリ内の自動更新も無効なので、起動時に更新の確認もしません。

## 外部へ送られるもの

利用状況の送信を止めても、すべての機能がオフラインになるわけではありません。ご自身で選んだサービスには、そのサービスを使うために必要なものが送られます。

| 使う機能 | 送り先 | 送られるもの |
|---|---|---|
| 外部の翻訳 API（DeepL、Gemini、OpenAI など） | 選んだサービス | 翻訳する文章 |
| 音声認識の Google エンジン（Windows） | Google | マイクの音声 |
| モデルの取得 | Hugging Face | ダウンロードの要求 |
| チャットボックスへの送信 | VRChat（この PC の OSC） | 送る文章 |

ローカルの翻訳モデル、同梱の speech.cpp サーバー（読み上げ・リアルタイム字幕）、チャット読み取りは、この PC の中で動きます。

## この PC に保存されるもの

- 設定ファイル（`config.json`）：外部の翻訳 API のキーも、ここに保存されます。
- ログ：アプリの動作の記録です。不具合を報告するときは、個人情報や会話の内容を消してから貼ってください。
- 会話のログ：「設定」→「その他」の「会話ログを自動的に保存する」をオンにしたときだけ、テキストファイルとして保存します。

保存先は [インストール](./install) と [困ったとき](./troubleshooting) を見てください。

## 待ち受けるサーバー

OBS ブラウザソースと WebSocket は、オンにしたときだけ動き、初期設定ではこの PC の中（`127.0.0.1`）だけで待ち受けます（[OBS と WebSocket](../features/integrations)）。
