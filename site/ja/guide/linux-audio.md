# Linuxの音声経路

読み上げや声の変換をVRChatに届けるには、VRCT-VOXの音声をVRChatのマイク入力へつなぐ必要があります。Linuxでは、VRCT-VOXが管理する仮想マイク（PipeWire）を作れます。

![「設定」→「デバイス」の画面](/screenshots/ja/device.webp)

## 管理対象の仮想マイクを使う

1. 「設定」→「デバイス」→「音声経路」で、「管理対象の仮想マイク（Linux）」を選んで保存します。準備が自動で始まります。「RVC」のページの「仮想マイクを準備して使用」からも始められます。
2. 準備が終わったら、「音声を再開」を押します。仮想マイクは、ミュートした状態で作られます。
3. VRChatのマイクに「VRCT Managed Virtual Microphone」を選びます。

管理者の権限は要りません。PipeWireと、systemdのユーザーサービスが使える環境が必要です。

### アプリがすること

- `vrct-managed-source`、`vrct-managed-tts`、`vrct-managed-vc`の3つのユーザーサービスを作り、有効にします。保存先は`~/.config/systemd/user/`です。
- 仮想マイクは、VRCT-VOXを終了しても残します。次にログインしたときは、ミュートした状態で作り直します。
- すでに正常な仮想マイクがあれば、それを使い回します。

### アプリがしないこと

- 音声サービス（PipeWireなど）の再起動
- マイクの録音の開始、モデルの取得
- 終了時の仮想マイクの削除。使っているアプリから突然マイクが消えると、別のマイクに切り替わるおそれがあるためです。

## ミュートと再開

「デバイス」→「音声経路」の「再開するまでミュート」は、この仮想マイクを通る読み上げと声の変換をまとめて止めます。再開するには「音声を再開」を押します。VRCT-VOXを起動し直したときは、ミュートした状態から始まります。

## 仮想マイクを消すとき

1. VRCT-VOXを終了します。
2. VRChatなど、仮想マイクを使っているアプリの入力を、別のマイクに切り替えます。
3. 上の3つのユーザーサービスだけを停止して、無効にします。

```sh
systemctl --user disable --now vrct-managed-source.service vrct-managed-tts.service vrct-managed-vc.service
```

## 既存の外部ケーブルを使う

すでに仮想ケーブルなどを用意しているときは、「音声経路」を「既存の外部ケーブル」にして、「TTS」の「出力デバイス」でそのケーブルを選びます。VRChatでは、ケーブルの録音側をマイクに選んでください。このとき「再開するまでミュート」が止めるのは、VRCT-VOXの読み上げだけです。
