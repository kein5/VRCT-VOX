# 声と文字の流れ

VRCT-VOXは声や文字を受け取り、文字にしたり訳したり声にしたりして、VRChatや画面へ渡します。このページではその流れを1枚の図で見渡します。

![声と文字の流れの図。上の段は自分の声とチャット入力が、音声認識と翻訳を通って、VRChatのチャットボックスと仮想マイクへ出る流れ。下の段は相手の声とチャットボックスが、音声認識かチャット読み取りと翻訳を通って、字幕とログ、OBSへ出る流れ](/diagrams/how-it-works-ja.svg)

## 自分から相手へ

図の上の段です。

- チャット入力は翻訳を通ってVRChatのチャットボックスへ出ます。
- 自分の声は音声認識（ASR）で文字になり、同じく翻訳を通ってチャットボックスへ出ます。
- 訳した文はテキスト読み上げ（TTS）で声にして仮想マイクへ出せます。
- 自分の声をボイスチェンジャー（RVC）で変えて、仮想マイクへ出すこともできます。
- 読み上げをボイスチェンジャーに通すと、訳した文を変えた声で届けられます（図の点線）。

翻訳がオフのときは、原文のまま次へ渡します。

## 相手から自分へ

図の下の段です。

- 相手の声（ゲーム音声）は音声認識（ASR）で文字になります。
- 相手のチャットボックスの文字はチャット読み取り（OCR）で文字になります。
- どちらも翻訳を通って、メイン画面のログと字幕に出ます。OBSやWebSocketにも渡せます。

聞き取った相手の声や、それを文字にした文を、自分のマイクやチャットボックスへ送ることはありません。

## 仮想マイクが必要な理由

VRChatが聞くのは、VRChatで選んだマイクの音だけです。VRCT-VOXが作った声（読み上げや変えた声）をVRChatへ届けるには、その声をマイクの音としてVRChatに渡す必要があります。仮想マイクは、アプリが出した音を、マイクの音としてほかのアプリに渡す仕組みです。

- Linuxでは、VRCT-VOXが管理する仮想マイクを用意できます（[Linuxの音声経路](./linux-audio)）。
- WindowsではVB-CABLEなどの仮想ケーブルを別に入れて使います。

VRChatのマイクには仮想マイク（仮想ケーブルの録音側）を選びます。

## スイッチと流れの対応

メイン画面のスイッチは図の線をつないだり切ったりします。

| スイッチ | つなぐ線 |
|---|---|
| 翻訳 | 文字を翻訳に通す |
| マイク入力 | 自分の声 → 音声認識（ASR） |
| 聞き取り | 相手の声 → 音声認識（ASR） |
| チャット読み取り（OCR） | 相手のチャットボックス → チャット読み取り |
| テキスト読み上げ（TTS） | 文字 → テキスト読み上げ → 出力先（仮想マイクなど） |
| ボイスチェンジャー（RVC） | 自分の声 → ボイスチェンジャー → 仮想マイク |

チャットボックスへ送るかどうかは、「設定」→「VRChat」の「VRChatにメッセージを送信する」で決めます。
