# 自分のモデルを使う

設定画面から取得できる既定のモデルのほかに、自分で用意したモデルも使えます。自分で学習したモデル、ほかの場所で配布されているモデル、購入したモデルです。

使えるかどうかは機能によって違います。

| 機能 | 使えるもの | 指定する所 |
|---|---|---|
| テキスト読み上げ（TTS） | GGUF のモデルと、声の GGUF（任意）。またはこの PC で動かすサーバー | 「テキスト読み上げ（TTS）」→「モデルとサーバー」 |
| 音声認識（ASR） | GGUF の認識モデル、VAD、話者分離（任意）。またはこの PC で動かすサーバー | 「音声認識（ASR）」→「モデルとサーバー」→「ASR + VAD」 |
| Whisper | 自分の Whisper サーバー（OpenAI 互換） | 「音声認識（ASR）」→「クラウド音声認識」→「カスタムWhisperサーバー」 |
| ボイスチェンジャー（RVC） | `.pth` のモデルと `.index`（任意） | 「ボイスチェンジャー（RVC）」 |
| Seed-VC | 参照の WAV | 「高度な設定」→「入力音声の転送」 |
| 翻訳 | LM Studio、Ollama、OpenAI 互換サーバーに入れたモデル | 「翻訳」→「ローカルLLM・互換サーバー」 |
| チャット読み取り（OCR） | 使えません | — |

設定画面の各モデルの欄にある「自分のモデルを使う方法」を押すと、このページの該当する節が開きます。

::: warning アプリは利用条件を確かめません
設定画面から取得するモデルは、提供元、ライセンス、容量を示して同意を得てから取得します。自分で指定したファイルについては、アプリは利用条件を確かめません。使ってよいかは自分で確かめてください（[購入したモデルと配布されているモデル](#bought-models)）。
:::

## テキスト読み上げ（TTS） {#tts}

### 使えるファイル

- 同梱の speech.cpp が読み込める、読み上げ用の GGUF のモデル。例は Irodori-TTS と Qwen3-TTS です。
- 声の GGUF（任意）。参照の録音から作った声のファイルで、Irodori-TTS で使えます。作り方は [speech.cpp](https://github.com/nyosegawa/speech.cpp) の `speech voice` の説明にあります。

### 指定する

1. 「設定」→「テキスト読み上げ（TTS）」の下のほうにある「モデルとサーバー」を開きます。
2. 「日本語TTS」か「多言語TTS」の「モデルGGUFのパス」にファイルの場所を入れます。日本語の読み上げには「日本語TTS」を、ほかの言語には「多言語TTS」を使います。
3. 声の GGUF を使うときは、「声GGUFのパス（任意）」に場所を入れます。
4. 「変更を保存」を押します。
5. 声の GGUF を使うときは、上の「日本語の声名」か「他言語の声名」に `custom` と入れて保存します。
6. メイン画面で「テキスト読み上げ（TTS）」をオンにします。サーバーはこのとき起動します。

### 自分で動かすサーバーを使う

この PC で speech.cpp のサーバーを自分で動かしているときは、「日本語のサーバー」などで「外部サーバー」を選び、URL を入れます。URL に使えるのは `127.0.0.1`、`localhost`、`::1` だけです。

### うまくいかないとき

| 出るメッセージ | 確かめること |
|---|---|
| この言語の同梱TTSサーバーに使えるモデルがありません | ファイルの場所が正しいか。拡張子が `.gguf` か |
| このモデルはこのサーバーの用途（読み上げ・認識）に合いません | 認識用のモデルを読み上げの欄に入れていないか |

声名を間違えると、読み上げるときに番号つきのエラーが出ます。声の GGUF を使うときは、声名が `custom` になっているかを確かめてください。

## 音声認識（ASR） {#asr}

### 使えるファイル

- 同梱の speech.cpp が読み込める、認識用の GGUF のモデル。例は Qwen3-ASR と Haas-ja です。
- VAD（発話の区切りの検出）の GGUF。認識モデルと一緒に必ず要ります。
- 話者分離の GGUF（任意）。

### 指定する

1. 「設定」→「音声認識（ASR）」の下のほうにある「モデルとサーバー」を開き、「ASR + VAD」を見ます。
2. 「モデルGGUFのパス」と「VAD GGUFのパス」にファイルの場所を入れます。話者分離を使うときは「話者分離GGUFのパス（任意）」にも入れます。
3. 「変更を保存」を押します。
4. メイン画面で「マイク入力」か「聞き取り」をオンにします。

この PC で自分の認識サーバーを動かしているときは、「リアルタイム字幕」の「ASRサーバー」で外部のサーバーを選び、URL を入れます。

### うまくいかないとき

| 出るメッセージ | 確かめること |
|---|---|
| 同梱ASRサーバーのモデルファイルが見つからないか、GGUFではありません | 認識モデルと VAD の場所が正しいか。拡張子が `.gguf` か |
| このモデルはこのサーバーの用途（読み上げ・認識）に合いません | 読み上げ用のモデルを認識の欄に入れていないか |
| このASRモデルは選んだ言語を認識できません | モデルが話す言語に対応しているか |

## Whisper のサーバー {#whisper-server}

アプリに入っている Whisper のモデルは、一覧にあるものだけです。ほかの Whisper のモデルを使いたいときは、OpenAI 互換の Whisper のサーバー（`/v1/audio/transcriptions`）を自分で動かし、そこにつなぎます。

1. 「設定」→「音声認識（ASR）」→「クラウド音声認識」で「カスタムWhisperサーバー」を開きます。
2. URL と、必要ならキーを入れて保存します。保存するとサーバーにつながるかを確かめ、モデルの一覧を読みます。
3. モデルを選び、上の「音声認識で使用するエンジン」で「カスタムWhisperサーバー」を選びます。

URL は HTTPS にします。HTTP を使えるのは、この PC（localhost）かローカルネットワークの IP アドレスのときだけです。

## ボイスチェンジャー（RVC） {#rvc}

### 使えるファイル

- RVC のモデル（`.pth`）。v1 か v2 で、標本化周波数が 32k・40k・48k のものです。
- 検索インデックス（`.index`）。任意です。「検索結果の混合率」を 0 より大きくするときは要ります。

RVC には実行環境も要ります。実行環境は設定画面から取得できます（[ボイスチェンジャー](../features/voice-conversion)）。NVIDIA の GPU が要ります。

### 指定する

1. 「設定」→「ボイスチェンジャー（RVC）」を開きます。
2. 下の「モデルと実行環境」を開き、「利用許可のあるRVCモデル（.pth）」にモデルの場所を入れます。インデックスがあれば「RVC検索インデックス（.index、省略可）」にも入れます。
3. 「変更を保存」を押します。
4. メイン画面で「ボイスチェンジャー（RVC）」をオンにします。

### うまくいかないとき

| 出るメッセージ | 確かめること |
|---|---|
| このモデルの形式には対応していません | モデルが v1 か v2 で、32k・40k・48k のものか |
| RVCモデル（.pth）か検索インデックス（.index）が見つかりません | ファイルの場所が正しいか |
| 検索インデックス（.index）を読み込めません | 別の `.index` を選ぶか、「検索結果の混合率」を 0 にする |
| モデルか基礎モデル（HuBERT）の中身が足りないか、形が合いません | モデルのファイルが壊れていないか。実行環境を取得し直す |

## Seed-VC {#seed-vc}

Seed-VC は参照の WAV の声に近づけるように声を変えます。

- WAV は PCM の形式で、長さは 1〜30 秒にします。
- 「設定」→「高度な設定」→「入力音声の転送」で「直接音声のモード」を「ボイスチェンジャー（試験的）」にし、「利用許可のある参照WAV」に場所を入れます。

自分以外の声を参照に使うときは、その人の許可が要ります。

## 翻訳 {#translation}

「AI翻訳（ローカル）」で使えるモデルは、一覧にあるものだけです。ほかのモデルで翻訳したいときは、モデルを LM Studio、Ollama、OpenAI 互換のサーバーに入れて、そこにつなぎます。

1. 使うサーバーにモデルを入れて起動します。
2. 「設定」→「翻訳」→「ローカルLLM・互換サーバー」で、使うサーバーの「接続確認」を押します。
3. モデルを選び、メイン画面の「翻訳エンジン」でそのサーバーを選びます。

詳しくは[翻訳](../features/translation#ローカルllmと互換サーバーを使う)を見てください。

## 購入したモデルと配布されているモデル {#bought-models}

自分で学習していないモデルは、使う前に提供元の利用規約を読んでください。とくに次の点を確かめます。

- VRChat の中で使ってよいか
- 配信や録画で使ってよいか
- クレジットの表示が要るか。要るなら、どこに何を書くか
- 改変してよいか
- 再配布してよいか

ほかにも気をつけることがあります。

- 実在する人の声を使ったモデルや参照の録音は、その人の許可が要ります。
- モデルのファイルをほかの人に渡すのは、規約で許されているときだけにしてください。
- 購入したときのライセンスの文面は、手元に残しておくと後で確かめられます。

## 使えないもの

チャット読み取り（OCR）の認識モデルとチャットボックス検出器は、設定画面から取得したものだけを使います。ファイルの容量とハッシュが一致したときだけ読み込むので、自分のモデルには置き換えられません。
