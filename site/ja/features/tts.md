# 読み上げ（TTS）

入力した文章や翻訳を声にして、VRChat が使う仮想マイクへ流します。チャットボックスへの文字の送信とは別に、オンとオフを切り替えられます。設定は「設定」→「TTS」にあります。

## 使う声

読み上げには、同梱の [speech.cpp](https://github.com/nyosegawa/speech.cpp) のサーバーを使います。

- **日本語**：Irodori-TTS
- **ほかの言語**：Qwen3-TTS

どちらのモデルも同梱していません。「同梱speech.cppサーバー」の「既定モデルのダウンロード」で取得します（[モデルの取得](../guide/models)）。すでに持っている GGUF ファイルを指定することもできます。

## はじめての手順

1. 「設定」→「TTS」の「同梱speech.cppサーバー」で、モデルを取得するか、GGUF のパスを入力します。
2. 上の「変更を保存」で保存してから、「サーバーを起動」を押します。保存しただけでは、モデルは読み込まれません。
3. 「読み上げ」を「原文」にします。翻訳を読ませたいときは「翻訳文」にして、「読み上げる翻訳先の番号」を選びます。
4. 「出力デバイス」で出力先を選びます。まずはイヤホンで試すのがおすすめです。一覧にないときは「デバイス一覧を更新」を押します。
5. メイン画面に戻り、「TTS」をオンにします。入力欄から文章を送ると、読み上げます。

::: tip VRChat へ声を届ける
VRChat で読み上げを聞かせるには、出力先を仮想マイクにして、VRChat のマイクにその仮想マイクを選びます。Linux では「管理対象の仮想マイク（Linux）」を使えます（[Linux の音声経路](../guide/linux-audio)）。Windows では、別に用意した仮想ケーブルを使います。
:::

## 自分でも聞く

「自分のスピーカーでも聞く」をオンにすると、VRChat へ送る音声と同じ読み上げを、自分のスピーカーやヘッドホンでも鳴らします。VRChat へ送る音声は変わりません。マイクが拾わないよう、ヘッドホンを使ってください。

## 止める

止め方は 3 つあり、止まる範囲が違います。

| 操作 | 止まるもの |
|---|---|
| メイン画面の「TTS」をオフ | 読み上げの受け付け・再生・待ち行列。文字の送信、RVC、翻訳は続きます |
| 「読み上げを停止・キューを消去」 | 今の読み上げと待ち行列だけ |
| 「デバイス」→「音声経路」→「再開するまでミュート」 | 音声経路全体（仮想マイクを使う場合は TTS と声の変換の両方） |

アプリを再起動すると、TTS と同梱サーバーはオフに戻ります。

## 低遅延待機（日本語・GPU）

「低遅延待機（Irodori・GPU）」をオンにすると、読み上げを始めるまでの時間を短くできます。待機中も GPU で短い計算を繰り返すため、消費電力が増え、ゲームと GPU を取り合うことがあります。初期設定はオフです。

::: warning 二重に読み上げられるとき
本家作者の VRCT-TTS など、同じチャットを読み上げる別のツールを動かしていると、二重に読み上げます。どちらかをオフにしてください。
:::
