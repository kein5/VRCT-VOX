# VRとオーバーレイ

VRの中で翻訳や字幕を見たり、機能を操作したりできます。設定は「設定」→「VR」にあります。字幕のオーバーレイとVR UIは、どちらもSteamVRを使う、本家VRCTから引き継いだ機能です。

![「設定」→「VR」の画面](/screenshots/ja/vr.webp)

## 字幕のオーバーレイ

メイン画面の上にある「Overlay(VR)」でオンにすると、VRの視界に翻訳や字幕を表示します。

- 「一行」と「複数行」の表示を切り替えられます。
- 位置と回転、透明度、サイズ、表示時間、フェードアウトの時間を調整できます。
- 「表示するトラッカーの位置」でHMD・左手・右手のどれに付けるかを選びます。
- 「サンプルテキストをOverlayに送信する」で見え方を確かめられます。
- 「翻訳後のメッセージのみ表示する」をオンにすると、原文を出さずに訳文だけを表示します。

## デスクトップの字幕オーバーレイ

ヘッドセットを使わずにVRChatを遊ぶときは字幕をデスクトップに出せます。「設定」→「VR」の「デスクトップの字幕オーバーレイ」で「デスクトップに字幕を表示する」をオンにします。Windowsで使えます。

- 会話ログに出た文をほかのウィンドウの上に重ねて表示します。
- 自分の発言（マイクや入力）は青、相手の発言（スピーカーやチャット読み取り）は紫の文字で出ます。会話ログと同じ色分けです。色帯も自分の発言は右、相手の発言は左に付きます。
- 字幕はクリックを通し、フォーカスも取りません。下にあるウィンドウをそのまま操作できます。
- 出す場所（画面の下・上）、文字の大きさ、表示時間、背景の濃さを変えられます。
- VRCT-VOXのメイン画面があるモニターに出ます。
- 「翻訳後のメッセージのみ表示する」はこの字幕にも当てはまります。

## VR UI（β版の機能）

「VR UIを表示する」をオンにすると、VRの中に、機能のオンとオフ、ログ、言語、設定を操作できる手首のランチャーとウィンドウを表示します。字幕のオーバーレイとは別に使えます。ランチャーが見つからなくなったら、「ランチャーの位置と大きさを初期に戻す」を押してください。左手首に戻ります。

::: warning 動作の確認について
VRの機能は、VRCT-VOXではまだ詳しく確かめていません。LinuxのVR UIはSteamVRの代わりになる試験用の仕組みで確かめただけで、実際のヘッドセットでは未確認です。デスクトップの字幕オーバーレイはWindows 11でほかのウィンドウの上に出ることを確かめました。VRChatの画面の上での見え方は未確認です。
:::
