# VR とオーバーレイ

VR の中で、翻訳や字幕を見たり、機能を操作したりできます。設定は「設定」→「VR」にあります。どちらも SteamVR を使う、本家 VRCT から引き継いだ機能です。

## 字幕のオーバーレイ

メイン画面の上にある「Overlay(VR)」でオンにすると、VR の視界に翻訳や字幕を表示します。

- 「一行」と「複数行」の表示を切り替えられます。
- 位置と回転、透明度、サイズ、表示時間、フェードアウトの時間を調整できます。
- 「表示するトラッカーの位置」で、HMD・左手・右手のどれに付けるかを選びます。
- 「サンプルテキストを Overlayに送信する」で、見え方を確かめられます。
- 「翻訳後のメッセージのみ表示する」をオンにすると、原文を出さずに訳文だけを表示します。

## VR UI（β版の機能）

「VR UIを表示する」をオンにすると、VR の中に、機能のオンとオフ、ログ、言語、設定を操作できる手首のランチャーとウィンドウを表示します。字幕のオーバーレイとは別に使えます。ランチャーが見つからなくなったら、「ランチャーの位置と大きさを初期に戻す」を押してください。左手首に戻ります。

::: warning 動作の確認について
VR の機能は、VRCT-VOX ではまだ詳しく確かめていません。特に Linux での動作は未確認です。VR UI のウィンドウの取り込みは、Windows の機能を使います。
:::
