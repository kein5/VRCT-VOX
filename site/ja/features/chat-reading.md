# チャット読み取り（OCR）

VRChatの画面に出たチャットボックスの文字を読み取り、ログに出したり翻訳したりします。設定は「設定」→「チャット読み取り」にあります。

![「設定」→「チャット読み取り」の画面](/screenshots/ja/chat-reading.webp)

## 準備

1. 「チャット読み取り」のページで、認識モデルを取得します。文字認識にはPaddleOCRのPP-OCR（Apache-2.0）を使います。提供元・ライセンス・容量を確かめてから、同意して取得してください（[モデルの取得](../guide/models)）。
2. VRChatを起動します。
3. ページの上の状態が「準備できています」になったら、メイン画面の「チャット読み取り」をオンにします。

## 読み取り言語

「auto」では、日本語・英語・中国語と、ラテン文字の言語を1つのモデルで読み取ります。ハングル・キリル文字・タイ文字・アラビア文字・デーヴァナーガリーは別のモデルが必要です。その文字を選んで、対応するモデルを取得してください。アラビア文字は、いまのところ精度が低めです。

## 読み取る場所

- 「読み取り範囲」では、VRChatのウィンドウのうち、読み取る部分を指定します。チャットボックスが出る場所だけを囲むと速くなり、ワールドの文字を拾いにくくなります。初期設定はウィンドウ全体です。
- 「チャットボックスらしい文字だけ読む」は、VRChatのチャットボックスと同じ、暗い板の上の明るい文字だけを残します。吹き出しを取りこぼすときはオフにしてください。オフにすると、ワールドの看板やメニューの文字も読み取ります。

## チャットボックス検出器

「チャットボックス検出器を使う（ダウンロード済みなら推奨）」をオンにすると、VRCT-VOX独自の検出モデルで吹き出しを1つずつ見つけてから読みます。吹き出しの取りこぼしや、ワールドの文字の誤読が減ります。

- モデルは任意です。なくても、読み取り範囲の中から吹き出しを探して読みます。
- モデルはYOLOX-Tiny（約19 MB、MIT）で、[Hugging Face](https://huggingface.co/kein5/vrct-vox-chatbox-detector)で公開しています。VRCT-VOX自身のスクリーンショットで学習したもので、本家VRCTのモデルではありません。
- 同じページの「チャットボックス検出器」から、条件を確かめて同意したうえで取得します（[モデルの取得](../guide/models)）。取得したファイルは、ハッシュが一致したときだけ使います。
- このPCのCPUで動き、画面の内容を送信することはありません。
- 読み取り範囲と「チャットボックスらしい文字だけ読む」は、検出器を使うときもそのまま効きます。

## 対応している環境

- Linuxでは、VRChatのウィンドウをX11/XWaylandから取り込みます。Protonの初期設定ではXWaylandで動くので、そのまま使えます。ネイティブのWaylandのウィンドウは、まだ取り込めません。
- Windowsでは、VRChatのウィンドウを取り込みます。

::: tip ウィンドウが見つからないとき
「ウィンドウ名」には、初期設定で`VRChat`が入っています。タイトルの違うクライアントを使っているときは、ここを変えてください。
:::
