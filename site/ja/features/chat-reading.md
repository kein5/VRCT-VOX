# チャット読み取り（OCR）

VRChat の画面に出たチャットボックスの文字を読み取り、ログに出したり翻訳したりします。設定は「設定」→「チャット読み取り」にあります。

## 準備

1. 「チャット読み取り」のページで、認識モデルを取得します。文字認識には PaddleOCR の PP-OCR（Apache-2.0）を使います。提供元・ライセンス・容量を確かめてから、同意して取得してください（[モデルの取得](../guide/models)）。
2. VRChat を起動します。
3. ページの上の状態が「準備できています」になったら、メイン画面の「チャット読み取り」をオンにします。

## 読み取り言語

「auto」では、日本語・英語・中国語と、ラテン文字の言語を 1 つのモデルで読み取ります。ハングル・キリル文字・タイ文字・アラビア文字・デーヴァナーガリーは別のモデルが必要です。その文字を選んで、対応するモデルを取得してください。アラビア文字は、いまのところ精度が低めです。

## 読み取る場所

- **読み取り範囲**：VRChat のウィンドウのうち、読み取る部分を指定します。チャットボックスが出る場所だけを囲むと速くなり、ワールドの文字を拾いにくくなります。初期設定はウィンドウ全体です。
- **チャットボックスらしい文字だけ読む**：VRChat のチャットボックスと同じ、暗い板の上の明るい文字だけを残します。吹き出しを取りこぼすときはオフにしてください。オフにすると、ワールドの看板やメニューの文字も読み取ります。

## 対応している環境

- **Linux**：VRChat のウィンドウを X11/XWayland から取り込みます。Proton の初期設定では XWayland で動くので、そのまま使えます。ネイティブの Wayland のウィンドウは、まだ取り込めません。
- **Windows**：VRChat のウィンドウを取り込みます。

::: tip ウィンドウが見つからないとき
「ウィンドウ名」には、初期設定で `VRChat` が入っています。タイトルの違うクライアントを使っているときは、ここを変えてください。
:::
