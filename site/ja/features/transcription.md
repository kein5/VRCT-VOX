# 音声認識とリアルタイム字幕

自分の声やほかのプレイヤーの声を文字にします。設定は「設定」→「音声認識」にあります。

![「設定」→「音声認識」の画面](/screenshots/ja/transcription.webp)

## リアルタイム字幕

同梱のspeech.cppの音声認識（ASR）サーバーを使って字幕を出します。字幕はメッセージのログと、有効にした大きいオーバーレイに表示します。

- 「マイクの字幕」は自分のマイクの声を文字にします。
- 「ゲーム音声の字幕」はVRChatの音声を文字にします。ゲーム専用の出力先を選んでください。共有の出力を選ぶとほかのアプリの音も字幕の対象になります。

メイン画面の「マイク入力」と「聞き取り」のスイッチで、それぞれの字幕を開始・停止します。同梱サーバーを選んでいれば、スイッチをオンにしたときにサーバーも起動します。アプリを再起動すると字幕は停止した状態に戻ります。

::: info ゲーム音声は送り直しません
聞き取ったゲーム音声を自分のマイクやチャットボックスへ送り直すことはありません。
:::

### 準備するもの

ASRサーバーには認識モデルとSilero VADの両方が必要です。ページの下のほうにある「モデルとサーバー」を開き、「ASR + VAD」で取得します（[モデルの取得](../guide/models)）。

![「設定」→「音声認識」の「モデルとサーバー」にある「ASR + VAD」の欄](/screenshots/ja/asr-models.webp)

| モデル | 言語 | 容量 | ライセンス |
|---|---|---|---|
| Haas-ja v1.0 · Q8_0 | 日本語だけ | 0.61 GiB | Apache-2.0 |
| Qwen3-ASR 0.6B · Q8_0 | 30言語。言語を自動で判定 | 0.78 GiB | Apache-2.0 |
| Silero VAD v6.2 · F32 | （発話の区切りを検出） | 約1.2 MB | MIT |

同梱サーバーが読み込む認識モデルは1つで、マイクとゲーム音声で共用します。日本語以外を話す相手がいるならQwen3-ASRを選んでください。言語を「自動判定（auto）」にするには、Qwen3-ASRのように言語を判定できるモデルが必要です。

### 話者の聞き分け

ゲーム音声の字幕に、誰が話したかのラベル（A、B…）を付けられます。「モデルとサーバー」→「ASR + VAD」で話者分離モデル（Nemotron 3 Diarization、約106 MB、OpenMDW-1.1）を取得して適用すると、次にサーバーを起動したときから働きます。使わないときは「話者分離GGUFのパス（任意）」を空にします。

- ログには「話者A」のように出ます。デスクトップの字幕オーバーレイでは文の前にラベルが付き、話者ごとに色が変わります。
- ラベルは声の特徴から推定したものです。名前は分かりません。似た声は同じ話者になることがあります。
- 発言の間が短いと、2人の発言が1つの字幕になります。そのときは「話者A・B」と両方を出します。
- ラベルはスイッチをオンにするたびに振り直します。
- 字幕が確定するまでの時間が0.3秒ほど延びます（RTX 3060 Tiでの値）。
- GPUが要ります。CPUだけでは間に合わないので、サーバーがCPUで動いているときはモデルがあってもラベルを付けません。
- マイクの字幕には使いません。

::: info 確かめた範囲
Windows 11で、読み上げの声で作った2〜6人の会話を使って確かめました。人の声では確かめていません。結果は開発者向けの[記録](https://github.com/kein5/VRCT-VOX/blob/develop/docs/voice-stack/speaker-diarization-2026-11-13.md)にあります。
:::

### 用語辞書

「用語辞書」に聞き取ってほしい言葉とその書き方を登録できます。VRChatでよく使う用語も初めから入っています。

## 音声タイピングモード

「設定」→「VR」の「音声タイピングモード」は、文字にした発言を、クリップボードを使って入力欄へ貼り付ける機能です。SteamVRが動いているときは、SteamVRで実行中のアプリ（VRChatなど）のウィンドウを前に出してから貼り付けます。SteamVRが動いていないときは、クリップボードへコピーするだけです。

LinuxではX11/XWaylandのウィンドウとして動いているアプリ（Protonで動くVRChatなど）に貼り付けます。KDEでは初めて貼り付けるときに、入力デバイスの操作を許可するかどうかをデスクトップが確認します。ネイティブのWaylandのウィンドウには貼り付けられないため、クリップボードへコピーするだけです。

## Windowsの音声認識

Windowsでは本家VRCTから引き継いだ音声認識（Google、Whisper）を「音声認識エンジン」で選べます。エンジンを選ぶ前に文字起こしをオンにすると、「音声認識エンジンを選ぶ」という画面が開きます。Googleはマイクやスピーカーの音声をGoogleの音声認識サービスへ送るエンジンです。WhisperはこのPCの中で音声を認識します。選んだエンジンから別のエンジンへ自動で切り替わることはありません。

リアルタイム字幕も使えます。「リアルタイム字幕」の「ASRサーバー」で「同梱サーバー」を選ぶと、メイン画面のマイクと聞き取りのスイッチがリアルタイム字幕を使います。
