# 入力と出力

いまの設定で自分の声とチャットがどこへ出るかを、図で見られます。直近の発言とチャットについては段階ごとにかかった時間も表示します。時間の単位はすべて ms（ミリ秒）です。

表示するだけの機能です。設定や音声の経路は変えません。

## メイン画面のパネル

メイン画面の上のバーで「入力と出力」を押すと、会話ログの上にパネルが開きます。もう一度押すか「閉じる」を押すと閉じます。

![「入力と出力」のパネル。左の自分の声とチャットから、翻訳や読み上げを通って右の届く先へ線が延びている](/screenshots/ja/io-flow.webp)

左に入力、真ん中に途中の処理、右に届く先を並べ、線でつないでいます。自分の声の線は青、チャットの線は紫です。

- 処理の箱には設定と時間を出します（例：翻訳 日本語 → 英語、212 ms）。
- 読み上げと声の変換は声とチャットで共通の箱です。マイクの声がそのまま声の変換へ入る線もあります。
- 届く先の箱には入力ごとの直近の時間と、そこで何をするかを出します。チャットボックスなら原文と訳文のどちらを送るか、VRChat に届く声なら変換したかどうかを示します。
- 使わない先は点線の箱になり、線は引きません。理由は図の下に並べます（例：設定でオフ、TTS がオフ）。
- 直近のメッセージが通った線は光ります。新しいメッセージが届くと、その線を光が一度走ります。
- VRChat が VRCT-VOX を通さずにマイクを使うときは、マイクから点々の線を引きます。

図の下には声とチャットのそれぞれについて、直近の 1 件の時間を段階ごとの棒で並べます。直近の合計時間の移り変わりと、その中央値も出します。

マイクがオフのときも、オンにしたら声がどこへ出るかを表示します。窓が狭いときは、図を横にスクロールできます。

### 時間の項目

| 項目 | 意味 |
|---|---|
| 音声認識 | 区切った音声の認識にかかった時間。リアルタイムでない音声認識のときだけ出ます。 |
| 待ち | リアルタイムの音声認識の結果を受け取ってから、処理を始めるまで |
| 翻訳 | 翻訳にかかった時間 |
| 出力へ渡す | 翻訳のあと、チャットボックスや字幕などへ渡し終えるまで |
| チャットボックス | VRChat へ送り終えた時点 |
| 読み上げ | 読み上げの最初の音を出した時点。声の変換を通すときは、変換へ送り始めた時点です。 |
| 声の変換（目安） | 声の変換の往復時間。その発言の値ではなく直近の中央値です。 |

### 数え始める時点

時間をどこから数えるかは入力によって違います。パネルにも書いてあります。

- チャットは送信をアプリが受け付けた時点から数えます。
- リアルタイムの音声認識は認識の結果が確定した時点から数えます。話し終えた時刻はアプリにはわからないので、話し終えてから確定するまでの時間は含みません。
- それ以外の音声認識は認識を始めた時点から数えます。

## デスクトップに表示する

「設定」→「VR」の「デスクトップの字幕オーバーレイ」で、「入力と出力をデスクトップに表示」をオンにします。直近の入力が通った道と、かかった時間を字幕の窓の左側に表示します。入力、翻訳、届いた先を矢印でつなぎます。字幕をオフにしていても使えます。

![画面の左下に入力と出力の表示があり、右側に字幕が重なっている](/screenshots/ja/flow-on-screen.webp)

背景は説明用の絵です。

- 表示する入力の数は「デスクトップに表示する入力の数」で 1〜3 件から選べます。最初は 1 件です。
- 声の変換が動いているときは、変換の往復時間も出ます。
- 字幕と同じくクリックを通してフォーカスも取りません。使える環境もデスクトップの字幕オーバーレイと同じです。

## VR の中で見る

VR UI をオンにしているときは、手首のランチャーで「入力と出力」を押すとウィンドウが開きます。メイン画面と同じ図と、いちばん新しい入力の時間を表示します。VR ではスクロールできないので、箱には名前と時間だけを出します。

![VR の「入力と出力」のウィンドウ](/screenshots/ja/vr-io-flow.webp)

## 記録の扱い

時間の記録はアプリの中だけで使います。ファイルに残したり外へ送ったりはしません。直近の分だけを持ち、アプリを閉じると消えます。

## 確かめた範囲

- Windows 11 の開発用のビルドで、チャットを送るとパネルとデスクトップの表示に時間が出ることを確かめました。翻訳と VRChat への送信はオフでした。
- 読み上げの時間が記録に加わることは、試験用の読み上げサーバーを使う自動試験で確かめました。
- マイクの発言、声の変換、VR の中の表示は、実機ではまだ確かめていません。VR のウィンドウは同じ大きさの試験用のページで見え方を確かめました。
