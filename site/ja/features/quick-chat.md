# 入力の小窓とホットキー

ゲームを続けたまま文章を送れる小さな入力の窓（小窓）と、キーを押して機能を切り替えるホットキーです。どちらも「設定」→「ホットキー」で設定します。

![「設定」→「ホットキー」の画面](/screenshots/ja/hotkeys.webp)

## 小窓から文章を送る

VRCT-VOXのメインのウィンドウを前に出さなくても、小窓から文章を送れます。メインのウィンドウを最小化していても使えます。小窓は開いている間、ほかのウィンドウより前に表示されます。

- 開くには「設定」→「ホットキー」で「チャット入力の小窓を開く」にキーを割り当てます。初期状態では未割り当てです。「入力の小窓を開く」ボタンからも開けます。
- Enterで送信し、Shift+Enterで改行します。
- Escで閉じます。下書きは残ります。

翻訳、チャットボックスへの送信、読み上げは、メインのウィンドウから送るときと同じように動きます。

### Linux（Wayland）での注意

ネイティブのWaylandではデスクトップのショートカットの仕組み（GlobalShortcuts portal）を使ってキーを登録します。初めて登録するときは、設定画面を閉じたときにデスクトップの確認画面が出ます。

- この仕組みに対応していないデスクトップでは、小窓は「入力の小窓を開く」ボタンから開いてください。
- ゲームの後ろに隠れた小窓をショートカットで前に出せるのは、KDE（KWin）だけです。
- XWaylandで動いているときは、ほかのWaylandのアプリを操作している間、ホットキーが届かなかったり、小窓が前に出なかったりすることがあります。

## ホットキー

「設定」→「ホットキー」で次の操作にキーを割り当てられます。初期状態ではどれも未割り当てです。

| 操作 | 動き |
|---|---|
| チャット入力の小窓を開く | 入力の小窓を開きます |
| VRCT-VOXの最小化/アクティブ化の切り替え | メインのウィンドウを最小化し、もう一度押すと元に戻します |
| 「翻訳」「マイク入力」「聞き取り」オン/オフの切り替え | メイン画面の同じ名前のスイッチを切り替えます |
| 読み上げを停止 | メイン画面の上の「読み上げ停止」と同じです |
| 音声のミュート/再開の切り替え | メイン画面の上の「ミュート」と同じです |
| 「テキスト読み上げ（TTS）」「ボイスチェンジャー（RVC）」オン/オフの切り替え | メイン画面の同じ名前のスイッチを切り替えます |

設定画面を開いている間は、誤って動かないようにホットキーは一時的に無効になります。

Waylandでは「VRCT-VOXの最小化/アクティブ化の切り替え」で最小化したウィンドウを、同じキーで元に戻せます。ほかのウィンドウの後ろから前に出せるのは、KDE（KWin）だけです。
