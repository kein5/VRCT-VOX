# 入力の小窓とホットキー

ゲームから手を離さずに文章を送る小窓と、キーで機能を切り替えるホットキーです。どちらも「設定」→「ホットキー」で設定します。

![「設定」→「ホットキー」の画面](/screenshots/ja/hotkeys.webp)

## 入力の小窓

本体を前に出さずに小さな窓から文章を送れます。本体が最小化されていても使えます。小窓は表示中、最前面に保たれます。

- 開くには「設定」→「ホットキー」で「チャット入力の小窓を開く」にキーを割り当てます。初期状態では未割り当てです。「入力の小窓を開く」ボタンからも開けます。
- Enterで送信し、Shift+Enterで改行します。
- Escで閉じます。下書きは残ります。

翻訳、チャットボックスへの送信、読み上げは、本体から送るときと同じように動きます。

### Linux（Wayland）での注意

ネイティブのWaylandではデスクトップのショートカット機能（GlobalShortcuts portal）でキーを登録します。初めて登録するときは、設定を閉じたときにデスクトップの確認画面が出ます。

- portalに対応していないデスクトップでは、ボタンから開いてください。
- ゲームの後ろに隠れた小窓をショートカットで前に出せるのは、KDE（KWin）だけです。
- XWaylandでは別のWaylandアプリを操作している間、デスクトップがキーやフォーカスの移動を制限することがあります。

## ホットキー

「設定」→「ホットキー」で次の操作にキーを割り当てられます。初期状態ではどれも未割り当てです。

| 操作 | 動き |
|---|---|
| チャット入力の小窓を開く | 入力の小窓を開きます |
| VRCT-VOXの最小化/アクティブ化の切り替え | 本体のウィンドウを最小化し、もう一度押すと元に戻します |
| 「翻訳」「マイク入力」「聞き取り」オン/オフの切り替え | メイン画面の同じ名前のスイッチを切り替えます |
| 読み上げを停止 | メイン画面の上の「読み上げ停止」と同じです |
| 音声のミュート/再開の切り替え | メイン画面の上の「ミュート」と同じです |
| 「TTS」「RVC」オン/オフの切り替え | メイン画面の同じ名前のスイッチを切り替えます |

設定画面を開いている間は、誤って動かないようにホットキーは一時的に無効になります。

Waylandでは「VRCT-VOXの最小化/アクティブ化の切り替え」で最小化したウィンドウを、同じキーで元に戻せます。ほかのウィンドウの後ろから前に出せるのは、KDE（KWin）だけです。
