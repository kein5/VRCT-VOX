# 翻訳

入力した文章や、音声認識で文字にした発言を翻訳します。メイン画面の「翻訳」でオンとオフを切り替え、「翻訳エンジン」でエンジンを選びます。設定は「設定」→「翻訳」にあります。

![「設定」→「翻訳」の画面](/screenshots/ja/translation.webp)

## ローカルの翻訳モデル（CTranslate2）

PCの中で翻訳するので、文章を外へ送りません。「AI翻訳（ローカル）」でモデルを選び、「ダウンロード」で取得します。

| モデル | 容量の目安 | ライセンス |
|---|---|---|
| m2m100_418M（初期設定） | 418 MB | MIT（商用利用可） |
| m2m100_1.2B | 1.2 GB | MIT（商用利用可） |
| nllb-200-distilled-600M | 600 MB | CC-BY-NC-4.0（非商用） |
| nllb-200-distilled-1.3B | 1.3 GB | CC-BY-NC-4.0（非商用） |
| nllb-200-3.3B | 3.3 GB | CC-BY-NC-4.0（非商用） |

::: warning NLLBは非商用ライセンスです
NLLBのモデルは商用目的では使えません。選ぶときや取得するときに確認が出るので、ライセンスを読んで同意したときだけ使えます。
:::

モデルによって翻訳できない言語があります。たとえばM2M100は、バスク語とテルグ語に対応していません。対応していない言語を選んでいると、警告が出て選択が元に戻るので、言語を選び直します。

「AI翻訳の処理デバイス」では、CPUとGPUのどちらで翻訳するかを選べます。

## 外部の翻訳API

DeepL、Plamo、Gemini、OpenAI、Groq、OpenRouterを使えます。それぞれAPIキーを登録してから、メイン画面の「翻訳エンジン」で選びます。

- 翻訳する文章は、選んだサービスへ送られます。
- APIキーは、このPCの設定ファイル（`config.json`）に保存されます。

## ローカルLLMと互換サーバー

LM Studio、Ollama、OpenAI互換のエンドポイントを使えます。「接続確認」でつながるかを確かめてから、モデルを選んでください。OpenAI互換のエンドポイントに公式以外のURLを指定するときは、料金・セキュリティ・互換性をご自身で確認してください。

## 使えないエンジン

Google、Bing、Papagoのウェブ翻訳は使えません。本家VRCTの翻訳エンジン部分が、公式のVRCTでだけ使えるライセンスになっているためです。
