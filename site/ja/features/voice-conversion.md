# 声の変換（RVC・Seed-VC）

マイクの声を、別に用意したRVCまたはSeed-VCの実行環境で変換し、仮想マイクへ流します。どちらも試験的な機能です。使う前にご自身の環境で音質と遅延を確かめてください。

![「設定」→「RVC」の画面](/screenshots/ja/rvc.webp)

## RVC

設定は「設定」→「RVC」にあります。

### 用意するもの

RVCのモデルだけでは動きません。次のものを別に用意する必要があります。

- RVCの実行環境（RVC-Projectのエンジン、Pythonの環境）
- HuBERTとRMVPE
- 利用が許可されている学習済みモデル（`.pth`）。必要に応じて、検索インデックス（`.index`）

実行環境、HuBERT、RMVPEは、設定の画面から取得できます。「RVCの実行環境」の欄で「取得内容を確認」を押し、ライセンス、サイズ、保存先を確認して同意します。同意するまで何も取得しません。終わったら「この実行環境を使う」を押して保存します。

取得にはNVIDIAのGPUとドライバーが必要です。通信量と必要な空き容量の目安は、Windowsで約3.6 GBと約12 GB、Linuxで約4.9 GBと約16 GBです。

自分で用意する場合の作り方はリポジトリの[integrations/rvc/README.md](https://github.com/kein5/VRCT-VOX/blob/develop/integrations/rvc/README.md)にあります。

既定のモデルとしてSaisho UtaneのRVC v2モデル（CC BY 4.0、約0.31 GiB）を「既定モデルのダウンロード」から取得できます。公開する作品や配信で使うときは作者のクレジット表示が必要です。

### 使い方

1. 「RVC実行環境のフォルダ」「利用許可のあるRVCモデル（.pth）」などを入力して保存します。
2. 変換した声の出口を用意します。
   - Linuxでは「仮想マイクを準備して使用」を押し、準備が終わったら「音声を再開」を押します。VRChatのマイクには「VRCT Managed Virtual Microphone」を選びます。
   - WindowsではVB-CABLEなどの仮想ケーブルを別に入れます。「設定」→「TTS」の「出力デバイス」でケーブルの再生側を選び、VRChatのマイクにはケーブルの録音側を選びます。
3. 「転送する入力」で自分が話すマイクを選びます。初期値は「デバイス」の「マイク」で選んだマイクです。
4. メイン画面の「RVC」をオンにします。

## Seed-VC

「設定」→「高度な設定」→「入力音声の転送」で「直接音声のモード」を「ボイスチェンジャー（試験的）」にすると使えます。Seed-VCの実行環境と、利用が許可されている参照音声（WAV）を指定します。実行環境は同じ画面の「Seed-VCの実行環境」の欄から取得できます。通信量と必要な空き容量の目安は、Windowsで約5 GBと約14 GB、Linuxで約6.4 GBと約18 GBです。

Seed-VCはGPL-3.0のエンジンで、対応するNVIDIAのGPUが必要です。

## 読み上げを変換後の声で届ける

「設定」→「TTS」の「読み上げを声の変換に通す」を「通す」にすると、声の変換が動いているあいだ、読み上げも変換してから仮想マイクへ流します。マイクの発言を翻訳して読み上げる設定（「確定した翻訳を読み上げる」）と組み合わせると、話した言葉の訳文を自分の変換後の声で届けられます。

- 読み上げているあいだは、マイクの代わりに読み上げを変換します。終わるとマイクに戻ります。そのため「直接音声と読み上げを混ぜる」とは一緒に使えません。
- 「直接音声を止める」を選んでいると、マイクの声は出さず、変換した読み上げだけを出します。
- 声の変換が動いていないときは、これまでどおり読み上げをそのまま出します。
- 変換の分だけ、聞こえるまでが少し遅れます。

## 注意

- 自分以外の声をモデルや参照音声に使うときは、その人の許可が必要です。
- 変換した声を自分でも聞くには、「TTS」の「自分のスピーカーでも聞く」をオンにします。
