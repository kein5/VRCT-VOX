# OBSとWebSocket

配信ソフトや自作のツールに翻訳や字幕を渡せます。設定は「設定」→「高度な設定」にあります。OBSブラウザソースとWebSocketは、どちらも初期設定ではこのPCの中（`127.0.0.1`）だけで待ち受けます。

![「設定」→「高度な設定」の画面](/screenshots/ja/advanced.webp)

## OBSブラウザソース

「OBSブラウザソースを有効化」をオンにすると、翻訳を表示するページを用意します。表示した文は一定時間たつとフェードアウトします。

1. 「OBSブラウザソースを有効化」をオンにします。
2. アプリの「OBS URL（クリックでコピー）」を押して、キーを含むURLをコピーします。ホストとポートが初期設定の場合は`http://127.0.0.1:2232/obs?token=<キー>`という形です。キーは画面では伏せて表示しますが、コピーしたURLには含まれます。
3. OBSで「ブラウザ」ソースを追加し、コピーしたURLを入れます。

すでにOBSブラウザソースを使っている場合も、アプリからURLをもう一度コピーして、OBSに設定したURLを更新してください。キーのないURLは使えなくなりました。コピーしたURLのキーで会話を受け取れるため、他人に共有しないでください。

最大メッセージ数、表示時間、フェードアウト時間、フォントの大きさと色、縁取りを変えられます。

## WebSocket

「WebSocketサーバーを有効にする」をオンにすると、翻訳や字幕をWebSocketで送ります。ホストとポートが初期設定の場合、URLは`ws://127.0.0.1:2231/?token=<キー>`という形です。「WebSocket URL（クリックでコピー）」でコピーできます。OBSのURLと同じキーを使います。

OBSブラウザソースを使っている間は、WebSocketの設定を変えられません。先にOBSブラウザソースを無効にしてください。

::: warning ほかのPCへ公開するとき
Hostを`127.0.0.1`以外にすると、同じネットワークのほかの機器からもつながるようになります。必要なときだけ変えてください。
:::
