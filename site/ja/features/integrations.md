# OBS と WebSocket

配信ソフトや自作のツールに、翻訳や字幕を渡せます。設定は「設定」→「高度な設定」にあります。どちらも、初期設定ではこの PC の中（`127.0.0.1`）だけで待ち受けます。

![「設定」→「高度な設定」の画面](/screenshots/ja/advanced.webp)

## OBS ブラウザソース

「OBS ブラウザソースを有効化」をオンにすると、翻訳を表示するページを用意します。表示した文は、一定時間たつとフェードアウトします。

1. 「OBS ブラウザソースを有効化」をオンにします。
2. 「OBS URL（クリックでコピー）」を押して、URL をコピーします。初期設定では `http://127.0.0.1:2232/obs` です。
3. OBS で「ブラウザ」ソースを追加し、コピーした URL を入れます。

最大メッセージ数、表示時間、フェードアウト時間、フォントの大きさと色、縁取りを変えられます。

## WebSocket

「WebSocketサーバーを有効にする」をオンにすると、翻訳や字幕を WebSocket で送ります。初期設定の URL は `ws://127.0.0.1:2231` です。「WebSocket URL（クリックでコピー）」でコピーできます。

OBS ブラウザソースを使っている間は、WebSocket の設定を変えられません。先に OBS ブラウザソースを無効にしてください。

::: warning ほかの PC へ公開するとき
Host を `127.0.0.1` 以外にすると、同じネットワークのほかの機器からもつながるようになります。必要なときだけ変えてください。
:::
