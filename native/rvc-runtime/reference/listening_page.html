RVC 聴き比べ（ABX）

本家実装（基準）と Rust 実装の出力を、どちらがどちらか分からない状態で聴き比べます。

進め方

1 回の試行では A・B・X の 3 つを聴きます。X は A か B のどちらかと同じ音声です。X がどちらと同じかを答えてください。聴き直しは何度でもできます。

合成にはランダムなノイズが入るため、本家どうしでも毎回わずかに違う音になります。そこで「本家と Rust」の組に加えて、「本家と本家（乱数だけ違う）」の組も対照として混ぜてあります。どの組かは表示しません。

ABX のあと、モデルごとに「同じ声・同じ言い回しに聞こえるか」を答えます（仕様書 13.2 の判定）。

ヘッドホンを推奨します。キー操作：A B X で再生、1 で「X は A」、2 で「X は B」、Space で停止。

X はどちらと同じですか。

分からないときも、どちらかを選んでください（当て推量でかまいません）。

音声 1 と音声 2 は、同じ声・同じ言い回しに聞こえますか。

結果

「正答」は X を当てた回数です。当て推量なら半分前後になります。p は、区別できていないと仮定したときにこの回数以上当たる確率です。「本家と Rust」の正答が「本家と本家」と同じ程度なら、Rust 実装は本家の乱数違いと聴き分けられていません。
